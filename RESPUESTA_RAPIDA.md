# Comandos para Descargar y Ejecutar la Última Versión

## 🎯 Respuesta Rápida

### Descargar y Ejecutar (3 comandos)

```bash
# 1. Clonar el repositorio
git clone https://github.com/xtremevice/WindowTabsFree-Net8-NUEVO.git

# 2. Entrar al directorio
cd WindowTabsFree-Net8-NUEVO

# 3. Ejecutar
dotnet run --project src/WindowTabsFree.UI/WindowTabsFree.UI.csproj
```

## ✅ Requisitos Previos

Necesitas tener instalado:
- **.NET 8 SDK** - Descarga desde: https://dotnet.microsoft.com/download/dotnet/8.0

Verificar instalación:
```bash
dotnet --version
# Debe mostrar 8.0.x
```

---

## 🔄 Para Actualizar a la Última Versión

```bash
cd WindowTabsFree-Net8-NUEVO
git pull origin main
dotnet run --project src/WindowTabsFree.UI/WindowTabsFree.UI.csproj
```
